# modern Layouts

슬라이드 타입별 레이아웃 명세.
좌표는 모두 inches 단위. 공통 Title Bar는 모든 슬라이드에 적용 (ppt-components.md 참조).

---

## hero

전체 슬라이드를 세로 중앙에 배치.

```
┌─────────────────────────────────────────────┐
│                                             │
│                                             │
│              [ accent line ]                │  y=2.05, w=3.0, h=0.05
│                                             │
│                  TITLE                      │  y=2.2, h=1.4, 40pt Bold, center
│                                             │
│                 subtitle                    │  y=3.7, h=0.8, 24pt, center
│                                             │
│                   cta                       │  y=4.65, h=0.5, 12pt, accent
│                                             │
└─────────────────────────────────────────────┘
```

## two-column

좌우 동일 너비 컬럼 (6.0" each). 중앙 0.3" 분리선.

```
┌──────────────────────┬──────────────────────┐
│ TITLE (full width)   │                      │  y=0.4
├──────────────────────┼──────────────────────┤
│ • Left item A        │ • Right item A       │  y=1.35
│ • Left item B        │ • Right item B       │
└──────────────────────┴──────────────────────┘
                       ↑ divider rect w=0.01"
```

## kpi

최대 4개 카드 균등 배치. 카드 높이 3.6", 수직 중앙 정렬.

```
┌─────────┬─────────┬─────────┐
│  TITLE (full width)         │
├─────────┬─────────┬─────────┤
│  $1M    │  10K    │  2.1%   │  ← value, 52pt Bold, accent
│  ▲+12%  │  ▼-3%   │  ▼-0.4% │  ← delta, caption
│ Revenue │  Users  │  Churn  │  ← label, muted
└─────────┴─────────┴─────────┘
```

## architecture

zone 기반 3×3 그리드. diagram 영역 = content 영역 전체.

```
┌─────────────────────────────────────────────┐
│ TITLE                                       │
├────────────┬────────────┬────────────────────┤
│ top-left   │ top-center │ top-right          │  row 0: cy≈2.31"
├────────────┼────────────┼────────────────────┤
│ center-    │ center     │ center-            │  row 1: cy≈4.15"
│ left/left  │            │ right/right        │
├────────────┼────────────┼────────────────────┤
│ bottom-    │ bottom-    │ bottom-            │  row 2: cy≈5.98"
│ left       │ center     │ right              │
└────────────┴────────────┴────────────────────┘
  col 0: cx≈2.67"  col 1: cx≈6.67"  col 2: cx≈10.67"
```

Node size: 1.8" × 0.65"

## summary

body + takeaways 패널 (takeaways가 있을 때).

```
┌─────────────────────────────────────────────┐
│ TITLE                                       │
├──────────────────────┬──────────────────────┤
│ • Body item A        │  Key Takeaways       │
│ • Body item B        │  1. Takeaway A       │
│ • Body item C        │  2. Takeaway B       │
│                      │  3. Takeaway C       │
└──────────────────────┴──────────────────────┘
  body: 55% width        panel: 45% width
```

body만 있을 때는 전체 너비 사용.
