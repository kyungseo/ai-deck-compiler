# teal Layouts

슬라이드 타입별 레이아웃 명세. modern과 동일한 구조이며, section_label chip이 있을 때 title Y가 0.62"로 이동한다.
좌표는 모두 inches 단위.

---

## hero

전체 슬라이드를 세로 중앙에 배치. section_label chip 미적용 (후속 P2).

```
┌─────────────────────────────────────────────┐
│                                             │
│              [ accent line ]                │  y=2.05, w=3.0, h=0.05
│                                             │
│                  TITLE                      │  y=2.2, h=1.4, 40pt Bold, center
│                                             │
│                 subtitle                    │  y=3.7, h=0.8, 24pt, center
│                                             │
│                   cta                       │  y=4.65, h=0.5, 12pt, accent
│                                             │
└─────────────────────────────────────────────┘
```

## agenda

```
┌─────────────────────────────────────────────┐
│ [SECTION LABEL CHIP]                        │  y=0.20, h=0.28 (section_label 있을 때)
│ TITLE                                       │  y=0.35 또는 0.62
├─────────────────────────────────────────────┤
│ ① Item A                                   │  y=1.45, badge 0.55"×0.55"
│ ② Item B                                   │  y=2.25
│ ③ Item C                                   │  y=3.05
│ ...                                         │
└─────────────────────────────────────────────┘
```

## two-column

좌우 동일 너비 컬럼 (6.0" each). 중앙 0.3" 분리선.

```
┌──────────────────────┬──────────────────────┐
│ [CHIP] TITLE (full)  │                      │
├──────────────────────┼──────────────────────┤ card y=1.75
│ • Left item A        │ • Right item A       │  y=2.05
│ • Left item B        │ • Right item B       │
└──────────────────────┴──────────────────────┘
                       ↑ divider rect w=0.01"
```

## kpi

최대 4개 카드 균등 배치. 카드 높이 3.6", 수직 중앙 정렬.

```
┌─────────┬─────────┬─────────┐
│  [CHIP] TITLE (full width)  │
├─────────┬─────────┬─────────┤ card y=1.75
│  $1M    │  10K    │  2.1%   │  ← value, 52pt Bold, accent
│  ▲+12%  │  ▼-3%   │  ▼-0.4% │  ← delta, caption
│ Revenue │  Users  │  Churn  │  ← label, muted
└─────────┴─────────┴─────────┘
```

## architecture

zone 기반 3×3 그리드. diagram 영역 = content 영역 전체.

```
┌─────────────────────────────────────────────┐
│ [CHIP] TITLE                                │
├────────────┬────────────┬────────────────────┤
│ top-left   │ top-center │ top-right          │  row 0: cy≈2.31"
├────────────┼────────────┼────────────────────┤
│ center-    │ center     │ center-            │  row 1: cy≈4.15"
│ left/left  │            │ right/right        │
├────────────┼────────────┼────────────────────┤
│ bottom-    │ bottom-    │ bottom-            │  row 2: cy≈5.98"
│ left       │ center     │ right              │
└────────────┴────────────┴────────────────────┘
```

Node size: 1.8" × 0.65"
